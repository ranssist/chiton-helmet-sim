## STL 로 줄 때 알아 둘 것

| 항목 | 내용 |
|---|---|
| 단위 | STL 에는 단위가 없다. CAD(퓨전·솔리드웍스 등)에서 뽑았으면 보통 **mm** → 축척 "배율(직접) 0.001" |
| 생성형(Meshy) | 치수가 아예 없다 → 축척 "머리둘레" 로 맞춘다. 규격 프리셋을 고르면 값이 채워진다 |
| 분할판 | 조각을 **떨어뜨려** 저장하면 판 개수·1장 면적까지 자동으로 잡힌다. 한 덩어리로 합쳐지면 1장으로 센다 |
| 두께 | **닫힌(solid) STL** 이어야 두께가 나온다. 면만 있는 서피스면 두께는 직접 입력한다 |
| 크기 | 100 MB 를 넘으면 업로드 대신 경로 입력을 쓴다 |

바이너리 STL·GLB 는 저장소에 올리지 않는다(`.gitignore` 처리). 친구들과 공유할 때는 파일을 따로 보낸다.

## 측정 기록 — `tactical_helmet_multi.stl` (Meshy, 2026-09-22)

바이너리 STL · 삼각형 5,272,344개 · 닫힌 솔리드 · **연결요소 1개**(겹판이 하나로 병합돼 있다).
축 방향은 Z 위, Y 앞뒤, X 좌우.

FAST SF L 기준(머리둘레 57.5 cm + 라이너 20 mm + 셸 4 mm → 바깥 둘레 72.6 cm)으로 축척한 결과:

| 항목 | 값 |
|---|---|
| 크기 | 19.2 × 26.7 × 19.6 cm |
| 셸 바깥 표면적 A | 1801 cm² (림 위 돔 1202 + 림 아래 599) |
| 투영 면적 | 421 cm² (격자 근사) |
| 셸 두께 | 3.86 mm (부피 ÷ 바깥면적) |
| 겹판 | 8장, 각 ~16°(호 3.2 cm) 간격, 단차 ~5 mm |
| 판 1장 면적 | 94–109 cm² (돔 구간 대표 ~100 cm²) |
| 곡률 반경 | 10.9 cm (참고) |

MICH/ACH L(58.5 cm)로 축척하면 전체가 1.7 % 커져 A 1851 cm², 두께 3.91 mm 가 된다.

측정 JSON: `tactical_helmet_multi.fastsf_L.json`

### 이 모델의 한계

- **판이 하나로 병합돼 있다.** 판 개수·1장 면적은 기하학적으로(반지름 프로파일의 톱니) 세어 낸 값이라
  추정이다. 정확히 하려면 판을 **떨어진 솔리드로** 내보낸다.
- 두께 3.86 mm 는 전체 평균이다. 부위별로 다르면 그 차이는 이 값에 안 나타난다.
- 업로드 위젯 한도는 600 MB 로 올려 뒀지만, 수백 MB 파일은 경로 입력이 빠르다.
