# 오차 예산 — 예측이 실제 실험과 얼마나 어긋나는가

기준 조건: 3/4" 크롬강 구, Bambu PLA Basic XY, 두께 3 mm, 고정 링 내반경 40 mm, 고정단, 참고 판정(Roark 굽힘응력 = 굽힘강도).
보정 전 예측은 **h50 = 1.00 m** 이다. 아래 수치는 `scripts/error_budget.py` 로 다시 계산할 수 있다.

```bash
PYTHONPATH=. .venv/Scripts/python scripts/error_budget.py
```

## 1. 파라미터 불확실성 (문헌 ± 를 그대로 반영)

| 항목 | h50 변화 |
|---|---|
| 굽힘강도 ±1σ (76 ± 5 MPa) | ∓13.2 % |
| 굽힘탄성률 ±1σ (2750 ± 160 MPa) | ∓6.0 % |
| 두께 ±0.05 mm (프린터 공차) | ±2.7 % |
| 링 내반경 +0.5 mm (치구 공차) | +2.5 % |
| 강구 E·ν 범위 (190–210 GPa, 0.27–0.30) | 0.0 % |
| **합성 (RSS)** | **±15 %** |

## 2. 모델 형태 오차 — 이쪽이 더 크다

| 항목 | h50 변화 | 시뮬레이터에서 없애는 방법 |
|---|---|---|
| 경계조건 고정단 → 단순지지 | **+78 %** | **판 강성 실측** (보정 탭 0번). 실측하면 이 항이 사라진다 |
| 판 관성 무시(SDOF)로 풀 때 | −22 % | 기본이 2자유도라 이미 반영돼 있다 |
| p_y 1.6Y → 3.0Y (Thornton 범위) | −11 % | 압흔 실측으로 p_y 보정 |
| 막 효과 누락 | −10 % (2 m 낙하 응력은 +13 %) | 막 강성 포함 옵션(기본 '자동': w/t > 0.2면 포함) |
| 전단 강성 생략 | 접촉시간 −3.7 % (Shivakumar 사례) | 미구현 — Ks 식을 원문에서 확인하지 못했다 |
| 변형률 속도, 인필 < 100 %, 어닐링, 층간 결합, 보이드 | **정량화 못 함** | 실측 보정(E50)으로 흡수 |

## 3. 결론

- **보정 전 예측은 "2배 이내" 수준으로 본다.** h50 을 1.0 m 로 예측했다면 실제는 대략 0.5–1.8 m 다.
- 단일 항목으로는 **경계조건 가정 하나가 78 %** 를 만든다. 물성 산포(±15 %)보다 훨씬 크다.
- **보정 후에는** 같은 구성·위치·두께를 재현하는 데 **±10–20 %** 다. 가상 데이터 기준으로 속도 RMSE 0.026 m/s,
  압흔 RMSE 0.010 mm, E50 95 % 신뢰구간은 시편 24개에서 ±9 %(일체형 center)–±36 %(seam) 였다.
  이 폭은 모델이 아니라 시편 수에서 오므로 `1/√n` 으로 줄어든다.

## 4. 줄이는 순서 (효과 큰 것부터)

1. **판 강성 실측** — 정적 압입 시험 5점이면 78 % 항이 사라진다. 가장 값싸다.
2. **시편 수** — 24개 → 100개면 신뢰구간이 절반
3. **압흔으로 p_y 보정** — 11 % 항 제거
4. **막 효과 포함** — w/t > 0.2 조건이면 10 % 항 제거 (기본 '자동')
5. **두께·링 반경 실측값 입력** — 5 % 항 제거

UI 의 '판 충돌' 탭에는 이 시나리오들을 한 번에 계산한 **예측 밴드**가 나온다.
어떤 항목이 아직 가정인지, 무엇을 재면 밴드가 좁아지는지 화면에서 바로 보인다.
